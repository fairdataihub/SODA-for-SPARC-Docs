## Background

The SPARC Dataset Structure requires that if a user has performance metadata that they include the unique identifier for each performance in the performances file and in the manifest file.

## Issue

At this point in time SODA does not include the performance ids in the manfiest file. This will have to be done manually by the uploader after the files have been created and uploaded to Pennsieve.

## Status

This known issue is in the research phase. Once the SODA team determines how best to add performance ids to the manifest file
a new version of SODA will release with this feature.
